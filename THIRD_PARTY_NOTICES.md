# Komponen pihak ketiga

APK ini membawa / mengunduh komponen berikut. Masing-masing punya lisensi sendiri.

| Komponen | Sumber | Lisensi |
|---|---|---|
| PRoot + loader | paket Termux | GPL-2.0-or-later |
| talloc | paket Termux | LGPL-3.0-or-later |
| QEMU user-mode (qemu-i386-static) | paket Debian `qemu-user-static` | GPL-2.0 (dan lainnya) |
| open.mp server | github.com/openmultiplayer/open.mp | MPL-2.0 |
| MariaDB | Alpine Linux (diunduh saat setup) | GPL-2.0 |
| Debian i386 rootfs | debuerreotype / Debian (diunduh saat setup) | berbagai (DFSG) |
| Alpine minirootfs | alpinelinux.org (diunduh saat setup) | berbagai |
| Apache Commons Compress | Apache | Apache-2.0 |
| XZ for Java | tukaani.org | Domain publik |
| AndroidX / Jetpack Compose | Google | Apache-2.0 |

Bila kamu mendistribusikan APK yang berisi binary GPL (PRoot, QEMU), kamu wajib menyediakan
source-nya atau penawaran tertulis untuk itu, dan memberi tahu pengguna lisensinya.
Proyek ini tidak berafiliasi dengan open.mp, Rockstar Games, atau Take-Two Interactive.
